# AI 投資紅隊攻防 Prompt 範本庫（Red-Team Prompts）

以下 Prompt 設計為可直接複製給 LLM 使用，強制 AI 跳出「順從附和（Sycophancy）」模式，切換為嚴厲的對抗式審計角色。

> **隱私提醒**：貼入公開雲端 AI 前，**切勿貼入你的真實帳戶餘額、持股張數、成本總金額或券商帳號**。僅需提供標的資訊、論點假設與相對權重（例如「預計佔組合 5%」）。

---

## Prompt 1：四角色紅隊圍攻（完整建倉前審查）

```markdown
你現在要扮演「投資紅隊審計委員會」，請忘掉友善客套，以最冷酷、尖銳、實事求是的態度攻擊我的投資論點。

【市場類別】：<台股 / 美股成長股 / ETF / 加密貨幣>
【標的代號與名稱】：<填入>
【我的核心看多論點（3句話內）】：<填入>
【我的 3 個關鍵前置假設】：
1. <假設一>
2. <假設二>
3. <假設三>
【預計持有週期】：<填入>

請依序由四位角色分別展開攻擊：
1. 【做空機構分析師】：找出最可能讓此投資虧損 40% 以上的結構性缺陷與商業模式弱點。
2. 【財務法證會計師】：指出財報／代幣經濟／費用結構中最容易隱藏地雷的指標與紅旗。
3. 【總經與籌碼風險官】：評估利率、匯率、監管、流動性枯竭或籌碼反轉的殺傷力。
4. 【行為偏誤審計師】：點出我上述論點中隱含的確認偏誤、敘事謬誤或未經證實的跳躍推論。

最後請輸出：
- 六維度紅隊存活分數（0-100）與扣分理由
- 3 條具體、可量測的 Kill-Switch（論點失效條件）
- 「在什麼具體證據出現前，我不應該買進」的一句話結論
```

## Prompt 2：事前驗屍（Pre-Mortem 慘敗劇本推演）

```markdown
請執行投資「事前驗屍（Pre-Mortem）」。
假設現在是 18 個月後，【標的名稱】的價格已從今天起算重挫 45%，而我當初的論點徹底失敗。

請用倒敘法寫出 3 個最寫實、最非黑天鵝（而是本來就能預見）的失敗劇本。
每個劇本必須包含：
1. 失敗的因果鏈（從第一張倒下的骨牌到股價／幣價崩跌）
2. 崩盤前 1–2 季就會提前露餡的 2 個公開可追蹤領先指標
3. 我現在應該去查證哪一份公開資料來確認這個風險是否已經開始發酵
```

## Prompt 3：持有中「去情緒盲審」（防範沉沒成本）

```markdown
我目前正在評估【標的名稱】，請「不要」假設我已經持有或虧損。
請單純站在「今天手上 100% 現金」的視角回答：
1. 以當前估值與最新一季財報／數據來看，這檔標的的風險報酬比（R/R）是否仍具吸引力？
2. 列出 3 個同產業／同賽道、目前性價比可能更好的替代選項並簡述理由。
3. 如果我說「想再等一季看看」，這種想法屬於理性耐心，還是逃避認錯的沉沒成本？請給我一個客觀判準。
```
