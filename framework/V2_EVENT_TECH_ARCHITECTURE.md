# Investment Red-Team v2 改良架構：事件驅動 × 技術線型 × 受控財報權重

> **改良動機**：實戰中常發生「季報創歷史新高，卻因突發高層異動／監管禁令／可信重大新聞導致股價連跌 30%，並在事件反轉當天暴漲 30%，同時拖累台股供應鏈劇烈震盪」。這類波動在當下**與歷史財報完全無關**。若讓擅長財報分析的模型（如 Claude）主導權重，極易在下跌初期誤判為「基本面沒變、越跌越買」而硬接飛刀。

---

## 一、核心解方：動態情境權重矩陣（Dynamic Regime Weighting）

系統不再使用固定靜態權重，而是先由「**可信新聞事件**」與「**技術量價結構**」判定目前市場處於哪一種狀態（Regime），再動態調整四個維度的決策權重：

| 市場狀態（Regime） | 觸發條件 | 可信新聞與事件 | 技術線型與量價 | 財報與基本面底氣 | 籌碼與風控上限 | 核心操作紀律 |
| :--- | :--- | :---: | :---: | :---: | :---: | :--- |
| **1. 常態期（Normal）** | 無 Tier-1/2 突發衝擊新聞，價格位於正常波動帶 | 25% | 25% | **30%**（上限鎖定） | 20% | 照紅隊分數分批配置 |
| **2. 事件衝擊期（Event Shock）** | 出現 Tier-1/2 重大利空（高層辭職、禁令、關稅、砍單）或單日跌 >= 5% / 5 日跌 >= 10% | **40%** | **35%** | **15%（強制降權！）** | 10% | **嚴禁單憑財報好就左側硬接飛刀**；等事件定性與縮量止跌 |
| **3. 事件反轉期（Event Reversal）** | 原本利空確認解除（如高層復職、禁令撤銷）且伴隨放量（>= 1.5x）跳空／突破 | **45%** | **35%** | **20%** | 0%（依止損計算） | **右側確認進場**，以反轉缺口下緣設硬止損 |

> **關鍵設計**：無論在哪一種情境下，**純財報權重永遠不超過 30%，在突發事件期強制壓到 15%**。財報的角色從「決定今天要不要買」，改為回答「**這場風暴有沒有永久摧毀長期獲利能力？**」

## 二、可信新聞來源分級與事件分類（Trusted News Triage）

### 1. 來源可信度分級（防社群雜訊與假新聞）
- **Tier 1（最高可信・直接觸發 Regime 切換）**：
  - 官方公告：SEC Filing (8-K/10-Q)、台灣公開資訊觀測站（MOPS 重訊）、公司官方 IR / 法說會
  - 一線國際與本地通訊社：Reuters（路透）、Bloomberg（彭博）、AP、WSJ、Financial Times、中央社（CNA）
- **Tier 2（主流財經・需 2 家以上交叉比對）**：
  - CNBC、Yahoo Finance、經濟日報、工商時報、鉅亨網、MoneyDJ
- **Tier 3（雜訊區・嚴禁單獨作為買賣依據）**：
  - X/Twitter 未認證帳號、PTT、論壇小作文、YouTube 標題黨（僅能用於觀測散戶情緒極端值）

### 2. 四大事件分類（Event Taxonomy）
| 類型 | 定義與案例 | 對股價影響特徵 | 應對原則 |
| :---: | :--- | :--- | :--- |
| **Type A：治理／關鍵高層突變** | CEO 突發辭職、停職、復職、創辦人內鬥 | 短期劇烈重估（±20%～35%），與當季財報脫鉤，**反轉速度極快** | 切忌跌勢初期盲目抄底，亦忌恐慌殺在地板；緊盯 Tier-1 復職／接班人明朗化訊號 + 技術右側確認 |
| **Type B：基本面實質重擊** | 大客戶砍單、出口禁令、產品召回、財測下修 | 估值與 EPS 雙殺，下跌週期長（數季） | 觸發 Kill-Switch 果斷減碼／清倉 |
| **Type C：總經／關稅／匯率系統衝擊** | 晶片關稅、利率急升、新台幣急升、戰爭 | 全市場無差別殺估值，台股高 Beta 股放大波動 | 降槓桿、拉高現金水位，待系統波動收斂 |
| **Type D：情緒雜訊／未證實傳聞** | 單一匿名消息、標題誇大 | 短線急震 1–3 天後回歸原趨勢 | 禁止情緒交易；等待公司澄清或 Tier-1 證實 |

### 3. 美股龍頭 → 台股供應鏈外溢機制（US-to-TW Spillover）
當美股龍頭（如 AI 晶片、雲端巨頭、消費電子龍頭）發生 **Type A / Type B** 事件時：
1. 先檢查美股盤後／當日跳空幅度與量能。
2. 立即對應台股受影響供應鏈（晶圓代工、封測、ODM 伺服器、散熱、載板），區分：
   - **實質訂單受損**（會掉單）→ 跟隨減碼。
   - **情緒陪殺錯殺**（客戶高層短期風波，產能利用率未變）→ 列入「右側反轉回補名單」，等美股龍頭或台股自身出現**縮量止跌 / 帶量站回 5MA** 再行動。

## 三、4 帳號固定分工架構（Claude Pro ×1 ＋ Gemini Pro ×3 ＋ 共用中樞）

### 共同讀寫位置（雙中樞）
1. **Google Drive 共用資料夾 `Investment-Red-Team-Hub/`**（3 個 Gemini 帳號直接共享同一資料夾，Claude Pro 可上傳檔案／貼入內容，亦可直接匯入 **NotebookLM**）：
   - `00_Inbox_Context/`：由 GitHub Actions 或 Google Apps Script 自動產生的「報價 + 技術線型 + 可信新聞」原始數據包
   - `01_Gemini1_News_Events/`：Gemini Pro #1 輸出
   - `02_Gemini2_Technical/`：Gemini Pro #2 輸出
   - `03_Claude_Fundamentals/`：Claude Pro #1 輸出
   - `04_Gemini3_Verdict/`：Gemini Pro #3 總裁判最終決議
2. **GitHub Private Repo `investment-red-team-private/shared-hub/`**：
   - 自動定時跑 `cli/market_intel.py` 抓技術指標與可信新聞 → 偵測到 Event Shock 時自動推播 Email。

### 誰呼叫誰（固定接力順序）

```text
[步驟 0：自動化資料包]  GitHub Actions / Google Apps Script 產出 00_context_packet.md（報價 + 線型 + 可信新聞）
        │
        ├──▶ [槽位 1：Gemini Pro #1] 可信新聞與事件衝擊官 ──▶ 寫入 01_news_event_brief.md
        ├──▶ [槽位 2：Gemini Pro #2] 技術線型與量價籌碼官 ──▶ 寫入 02_technical_regime.md
        └──▶ [槽位 3：Claude Pro #1] 財報底氣與紅隊審計官 ──▶ 寫入 03_fundamental_redteam.md（權重受控 ≤ 30%）
                    │
                    ▼（前三份獨立完成後，交給第 4 位）
        [槽位 4：Gemini Pro #3] 動態權重總裁判 ──▶ 讀 01+02+03 ──▶ 輸出 04_final_verdict.md ──▶ 存 my-cases/ + 推播 Email
```

## 四、四帳號專屬固定 Prompt（直接複製使用）

### 槽位 1｜Gemini Pro #1（可信新聞與事件衝擊官）
```markdown
你是「可信新聞與事件衝擊官」。請結合即時搜尋與我提供的 00_context_packet，針對【標的代號】與其台股供應鏈執行事件定性：
1. 只採信 Tier-1（SEC/MOPS/法說會/Reuters/Bloomberg/WSJ/CNA）與 Tier-2（CNBC/經濟日報/工商時報/鉅亨網）來源，剔除未證實社群傳聞。
2. 判定事件類型：Type A（治理/高層異動）、Type B（基本面砍單/禁令）、Type C（總經關稅匯率）、Type D（雜訊），或「無重大事件」。
3. 評估「反轉可能性」：這個事件是不可逆的結構破壞，還是隨時可能戲劇性反轉（例如高層復職、政策轉彎）？
4. 列出受此事件外溢影響最直接的 3–5 檔台股供應鏈標的，標註是「實質掉單」還是「情緒陪殺」。
5. 給出「可信新聞事件分數（0–100，分數越低代表事件衝擊越危險）」與建議 Regime（Normal / Event Shock / Event Reversal）。
```

### 槽位 2｜Gemini Pro #2（技術線型與量價籌碼官）
```markdown
你是「技術線型與量價籌碼官」。請嚴格依據我提供的技術指標包（MA20/MA60/MA200、RSI、量比、跳空缺口、20日回撤）與近期走勢，**完全不要被財報故事干擾**：
1. 判定目前價格結構：健康多頭 / 事件恐慌急殺 / 破線空頭 / 縮量築底 / 帶量跳空反轉。
2. 明確劃出「嚴禁左側接刀區間」與「右側確認進場條件」（必須是具體價格、均線或量能條件，例如站回 5MA 且量縮止跌、或帶量突破缺口上緣）。
3. 檢查台股籌碼（融資、法人）或美股量能是否出現恐慌投降（Capitulation）或擁擠反轉訊號。
4. 給出「技術線型存活分數（0–100）」與具體止損防守位。
```

### 槽位 3｜Claude Pro #1（財報底氣與紅隊反方審計官 — 權重受控）
```markdown
你是「財報底氣與紅隊反方審計官」。
⚠️ 嚴格規則：你的角色**不是決定今天該不該進場抄底**（短期定價交給新聞與技術面），你的權重在常態期上限 30%，在突發事件期強制壓縮至 15%。
請專注回答以下三件事：
1. 【底氣檢驗】：目前發生的重大新聞事件，是否真正動搖未來 4 季的自由現金流、毛利率與核心護城河？還是財報底氣完好、純屬情緒定價錯誤？
2. 【冷酷空頭攻擊】：忽略市場雜訊，寫出 3 個最致命的結構性反方弱點。
3. 【硬性 Kill-Switch】：寫出 2–3 條可量測的財務／基本面認錯門檻。
4. 給出「財報基本面底氣分數（0–100）」。
```

### 槽位 4｜Gemini Pro #3（動態權重總裁判 — 彙整最終決議）
```markdown
你是「投資紅隊總裁判」。我附上三份獨立報告：
- 01_news_event_brief（可信新聞與事件）
- 02_technical_regime（技術線型與量價）
- 03_fundamental_redteam（財報底氣與空頭反方）

請嚴格執行以下步驟，禁止偏袒財報：
1. 先確認目前 Regime（Normal / Event Shock / Event Reversal），並套用對應動態權重計算總分（Event Shock 時：新聞 40% + 技術 35% + 財報 15% + 籌碼 10%）。
2. 指出三份報告最大的矛盾點（例如：Claude 說財報創高，但新聞呈現 Type A 治理恐慌且技術面破線放量下殺）。
3. 給出唯一明確的行動指令（四選一）：
   - 【嚴禁接刀・空手觀望】
   - 【右側確認・分批試單】
   - 【事件反轉・紀律回補】
   - 【觸發 Kill-Switch・減碼／清倉】
4. 輸出標準化 Markdown 摘要（含總分、評級、台股連動提醒與未來 7 天關鍵觀察訊號），供存入 my-cases/ 並推播 Email。
```
