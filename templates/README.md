# 四大市場紅隊審計範本（4-Market Templates）

不同市場的失效模式截然不同：台股重視月營收與法人／家族治理，美股成長股致命傷常在 SBC 稀釋與倍數壓縮，ETF 常見內扣費用與成分股集中盲點，加密貨幣則必須嚴審代幣解鎖、真實協議收入與合約／託管歸零風險。

| 市場 | 範本檔案 | 核心紅隊攻擊重點 |
| :--- | :--- | :--- |
| **台股（TW Stock）** | [`tw-stock.md`](./tw-stock.md) | 月營收動能、毛利率與存貨週轉、法說會指引落差、三大法人／融資籌碼、殖利率陷阱、匯率與家族治理 |
| **美股成長股（US Growth）** | [`us-growth.md`](./us-growth.md) | Rule of 40、SBC 股權稀釋、NRR 與客戶流失、FCF 轉換率、遠期估值倍數壓縮、大客戶／巨頭擠壓 |
| **ETF** | [`etf.md`](./etf.md) | 追蹤誤差、真實內扣費用（TER）、成分股／產業集中度、換股週轉率、折溢價、配息來源（是否平準金／左手換右手） |
| **加密貨幣（Crypto）** | [`crypto.md`](./crypto.md) | FDV vs 流通市值、代幣解鎖拋壓、協議真實手續費收入、智能合約與跨鏈橋風險、託管／監管與流動性枯竭 |

## 使用方式

1. 將對應範本複製至**私有倉庫** `investment-red-team-private/my-cases/` 中填寫（**請勿在本公開倉庫填入個人真實倉位或金額**）。
2. 可使用 `python3 -m cli.quote_fetch ... --format markdown` 抓取最新公開報價區塊貼入報告開頭。
3. 完成後將六維分數填入 [`dashboard/index.html`](../dashboard/index.html) 檢視雷達圖與倉位閘門建議。
